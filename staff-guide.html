Staff & Concierge Guide

How to use the Enforcement and Admin portals day to day — common tasks, and who to contact when something needs Regent Parking's help directly.

Using the Enforcement Portal

Four tabs, each built for a different moment: Valid Plates for desk lookups, 🚶 Patrol View for walking the garage, 🚩 Flagged for cars you found that aren't registered, and 🔍 Plate Lookup for checking one plate at a time.

Valid Plates
1

View active registrations

Loads automatically and shows every currently registered plate with unit, registration time, and expiry. Auto-refreshes periodically.

2

Search a plate

Type any part of a plate into the search box — the table filters instantly.

3

Export a record

Click ⬇ Export CSV for shift handovers or incident reports.

🚶 Patrol View
1

Walk the garage with a phone, not a desk

Just plate and unit, in large text. Exempt vehicles show a blue "EXEMPT" badge.

2

Tap a row to check it off

Dims the row with a strikethrough. A counter shows "X of Y checked," and progress is saved automatically — it resets the next day.

3

Reset checks for the next round

Tap the small Reset checks link next to the counter and confirm.

🚩 Flagged
1

Log a car that isn't registered or exempt

From Patrol View, tap the floating 🚩 Flag Vehicle button — plate, spot/location, and an optional description. Timestamped automatically.

2

Review and call it in

Tap Copy list to copy every flagged vehicle as plain text, ready to read off your phone when calling the city.

3

Clear once handled

Remove one vehicle, or clear the whole list (with confirmation) once everything's been called in. Stored only on this device, never sent to Regent Parking.

Using the Admin Portal

Five tabs: Vehicle Exemptions, 🔑 Unit Codes, 🅿️ Visitor Spots, 📜 Registration History, and ⚙️ Settings.

Vehicle Exemptions
+

Adding an exemption

Click + Add Exemption. Enter the plate, an optional note, and a start/end date.

✏

Editing

Click the pencil on any row to update plate, notes, or dates.

🗑

Removing

Click the trash icon and confirm. Expired exemptions stay visible, greyed out — use Active only to hide them.

🔑 Unit Codes
+

Adding a code

Click + Add Unit Code, enter the unit number, and either type a code or hit ⚄ Generate. Share it privately with the resident.

↺

Resetting

Edit the unit, generate or type a new code, save — the old one stops working immediately.

🗑

Removing

Click the trash icon and confirm. The resident can't register visitors until a new code is assigned.

ℹ️
Setting up many units at once (e.g. onboarding a new tower) is a one-time step Regent Parking runs on request — not a routine task here. Email support@regentparking.ca to request it.
🅿️ Visitor Spots
1

Optional, and specific to this building

Off by default. Switching buildings above configures a different one — this isn't a whole-account setting like Settings below.

2

Turn it on and set a range

Check the box, enter a prefix (e.g. "V") and a first/last spot number. The preview shows exactly what residents will see before you save.

3

Residents then pick a spot at registration

A required dropdown appears on the registration form, and the chosen spot shows up next to the plate in Enforcement, Patrol View, and Registration History.

ℹ️
This is a label, not a reservation — nothing stops two residents from picking the same spot. It's there for enforcement's reference, the same way the rest of this app treats registration as a pass rather than a booking.
📜 Registration History
1

Search by plate or unit

Toggle the mode, then enter a plate or unit number.

2

Review, active or expired

Most recent first, going back up to 3 years.

3

Export if needed

⬇ Export CSV, same as elsewhere.

⚙️ Settings
1

Set your pass limits

Monthly passes per unit, and days a single plate can stay registered — applied across every building under your account.

2

Applies immediately

New registrations and extensions use the updated numbers right away.

Common Scenarios
❓ A resident says their visitor is registered but it's not showing up
Search the plate in Enforcement. If it's not there, the registration may have expired — each pass is valid for a limited window (see Registration History for exact timing). Ask the resident to register again, or try refreshing the page first.
❓ A resident says their unit code isn't working
Go to Admin → Unit Codes and confirm the code matches what they're entering (codes are case-insensitive). Reset it if needed and share the new one privately.
❓ A resident is blocked because they've hit their monthly limit
A specific resident's current-month count can't be overridden — it resets on the 1st. If the limit itself is too low going forward, use Admin → Settings to raise it for future registrations.
❓ A contractor or vendor needs parking for multiple days
Add a Vehicle Exemption with the right start/end dates. Exempt vehicles bypass resident registration entirely and won't be flagged by enforcement.
❓ A new resident needs a unit code
Admin → Unit Codes → + Add Unit Code. If a code already exists for that unit (previous tenant), reset it first.
❓ Our building wants residents to pick a visitor spot at registration
Admin → 🅿️ Visitor Spots → enable it and set your building's prefix and spot range (e.g. V1–V20). Takes effect immediately on the registration form — no need to contact Regent Parking.
❓ You forgot your own staff password
Click Forgot password? on the login page — fully self-service.
❓ A new staff member needs portal access
Staff accounts are set up by Regent Parking, not from within either portal. Email support@regentparking.ca with the person's name, email, and which building they support — they'll get an invite email to set up their own account.
Security Reminders
🔐
  • Never share your staff login credentials with residents or anyone else.
  • Unit codes go directly to the resident of that unit — never posted publicly.
  • If a unit code may be compromised, reset it immediately from Admin.
  • If your own password may be compromised, reset it immediately via Forgot password?.
  • Always sign out on a shared workstation.
