Your Two Portals
🚔

Enforcement Portal

Day-to-day plate lookups

  • View all active visitor registrations, with search and CSV export
  • 🚶 Patrol View — a big, glanceable plate list built for walking the garage on a phone
  • 🚩 Flag unregistered vehicles found on patrol, then copy the list to call it in
  • 🔍 Look up any single plate to confirm it's valid or exempt
⚙️

Admin Portal

Exemptions, unit codes & settings

  • Add / edit / remove plate exemptions with date ranges
  • Create, reset, or remove individual resident unit codes
  • 📜 Look up 3 years of registration history by plate or unit
  • ⚙️ Set your building's monthly pass and per-plate day limits
Signing In
1

First time? Check your email for an invite

New staff receive an email invite from Regent Parking with a link to set up their own password (8 characters minimum). If you don't have an account yet, ask management to request an invite — see Common Scenarios below.

2

Go to either portal URL and sign in

Both portals redirect you to the login page automatically if you're not signed in. Enter your email and password.

3

Forgot your password?

Click Forgot password? on the login page and enter your email — you'll get a reset link by email. No need to ask management. You can also change your password anytime via 🔒 Password in the top-right nav while signed in.

⚠️

Session tip

Your session stays active in the browser. If you share a computer, always click Sign Out when you're done.

Using the Enforcement Portal

Four tabs, each built for a different moment: Valid Plates for desk lookups, 🚶 Patrol View for walking the garage, 🚩 Flagged for cars you found that aren't registered, and 🔍 Plate Lookup for checking one plate at a time.

Valid Plates tab

1

View active registrations

The table loads automatically and shows all plates currently registered with their unit, registration time, and expiry time. It auto-refreshes periodically.

2

Look up a specific plate

Type any part of a plate number into the search box — the table filters instantly.

3

Export a record

Click ⬇ Export CSV to download the current registrations as a spreadsheet — useful for shift handovers or incident reports.

🚶 Patrol View tab

1

Walk the garage with a phone, not a desk

Shows just plate and unit, in large text — nothing to squint at while walking a row of cars. Exempt vehicles are clearly marked with a blue "EXEMPT" badge.

2

Tap a row to check it off

Tapping dims the row with a strikethrough so you can track which cars you've confirmed. A counter shows "X of Y checked," and progress is saved automatically if you lose signal mid-walk — it resets the next day.

3

Reset checks for the next round

Tap the small Reset checks link next to the counter and confirm — clears every checkmark without affecting anyone's actual registration.

🚩 Flagged tab

1

Log a car that isn't registered or exempt

From Patrol View, tap the floating 🚩 Flag Vehicle button, then enter the plate, spot/location, and an optional description (e.g. "Black SUV"). It's timestamped automatically.

2

Review and call it in from the Flagged tab

Tap Copy list to copy every flagged vehicle as plain text — ready to read straight off your phone when calling the city.

3

Clear the list once it's handled

Remove a single vehicle with the one-tap Remove button, or clear the whole list (with a confirmation prompt) once everything's been called in. Flagged vehicles are stored only on this device, never sent to Regent Parking's database.

Using the Admin Portal

The Admin Portal has four tabs: Vehicle Exemptions, 🔑 Unit Codes, 📜 Registration History, and ⚙️ Settings. Use the tab bar to switch between them; the + Add button (where it appears) changes based on the active tab.

Vehicle Exemptions tab

+

Adding an exemption

Click + Add Exemption. Enter the plate, an optional note (e.g. "HVAC Contractor"), and a start and end date. The vehicle will not be ticketed during that date range.

✏

Editing an exemption

Click the ✏ pencil button on any row to update the plate, notes, or dates.

🗑

Removing an exemption

Click the 🗑 trash button and confirm. Expired exemptions remain visible but are greyed out — use the Active only filter to hide them.

Unit Codes tab

+

Adding a unit code

Click + Add Unit Code. Enter the unit number and a code, or hit ⚄ Generate for a random one. Share the code privately with the resident.

↺

Resetting a unit code

Click ✏ Edit on the unit, type a new code (or generate one), and save. The old code stops working immediately. Give the new code to the resident.

🗑

Removing a unit code

Click 🗑 and confirm. The resident will be unable to register visitors until a new code is assigned.

ℹ️

Setting up many units at once

Admin's Unit Codes tab handles one unit at a time, by design — bulk-generating codes for an entire building (e.g. onboarding a new tower) is a one-time setup step done by Regent Parking on request, not a routine staff task. Email support@regentparking.ca to request it.

📜 Registration History tab

1

Choose By Plate or By Unit

Toggle the search mode, then enter a plate or unit number.

2

Review every registration, active or expired

Results show most recent first, going back up to 3 years — useful for board questions about who parked where and when.

3

Export if needed

Use ⬇ Export CSV the same way as elsewhere in the app, for incident reports or board packages.

⚙️ Settings tab

1

Set your monthly pass limit and per-plate day limit

Change how many visitor passes each unit gets per month, and how many days a single plate can stay registered — both apply across every building under this account, not per-building.

2

Changes apply immediately

New registrations and extensions use the updated numbers right away. There's no separate "save and confirm" step beyond submitting the form.

Common Scenarios
❓A resident says their visitor is registered but it's not showing in the enforcement portal
Search the plate in the enforcement portal. If it doesn't appear, the registration may have expired. Ask the resident to register again — each pass is only valid for 24 hours. If they just registered, try refreshing the page.
❓A resident says their unit code isn't working
Go to the Admin Portal → Unit Codes tab and search for their unit. Confirm the code matches what they're entering. If needed, use ✏ Edit to reset it and give them the new code. Codes are case-insensitive.
❓A resident is blocked because they've hit their monthly limit
A specific resident's current-month count cannot be overridden — it resets on the 1st of the month. If the limit itself is too low for your building going forward, a board-authorized staff member can raise it any time in the Admin Portal's ⚙️ Settings tab; that applies to future registrations, not the current block.
❓A contractor or vendor needs parking for multiple days
Add a Vehicle Exemption in the Admin Portal with the appropriate start and end dates. Exempt vehicles bypass the resident registration flow entirely and will not be flagged by enforcement staff.
❓A new resident has moved in and needs a unit code
Go to the Admin Portal → Unit Codes tab → + Add Unit Code. Enter their unit number, generate a code, and share it with them privately. If a code already exists for that unit (previous tenant), reset it first.
❓You forgot your own staff password
Click Forgot password? on the login page and enter your email — you'll get a reset link. This is self-service; you don't need to ask management or Regent Parking.
❓A new staff member needs portal access
Staff accounts are set up by Regent Parking, not from within either portal. Email support@regentparking.ca with the new staff member's name, email, and which building they support — they'll receive an invite email to set up their own account.
🔐

Security reminders

  • Never share your staff login credentials with residents or other unauthorized individuals.
  • Unit codes should only be shared directly with the resident of that unit — not posted publicly.
  • If you suspect a unit code has been compromised, reset it immediately from the Admin Portal.
  • If you suspect your own staff password has been compromised, reset it immediately via Forgot password? on the login page.
  • Always sign out when leaving a shared workstation.
